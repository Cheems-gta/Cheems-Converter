# Cheems Converter

Offline Android video and audio converter powered by FFmpegKit.

Supports MP4, MKV, MOV, AVI, WebM, FLV, WMV, 3GP, MPEG, TS, GIF, MP3, M4A, WAV, FLAC, OGG, Opus and AAC.

**Work in progress:** Android APK build has not yet been verified on GitHub Actions or a real phone. The conversion command generator passed 18 desktop FFmpeg output-format tests.

Use `.github/workflows/android-apk.yml` to build a debug APK. No media uploads, analytics, or internet permission are required by the app.
